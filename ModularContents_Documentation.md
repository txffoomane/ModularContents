# Полное руководство по созданию контента для ModularContents

Мод **ModularContents** (версия для Forge 1.12.2) позволяет создавать собственные предметы, блоки, инструменты, еду, рецепты, вкладки креатива, кастомные верстаки и механики лута/аирдропов **без знания Java**.

Весь контент настраивается через простые `JSON`-файлы в папке игры либо через **Внутриигровой визуальный редактор (нажмите F8 в игре)**.

---

## 1. Структура Контент-Пака

Паки хранятся в корневой директории игры в папке `ModularContents`.
Вы можете создавать неограниченное количество паков. Мод поддерживает **папочную структуру**, которая автоматически настраивает многие вещи (например, если положить рецепт в папку `recipes/handcraft`, мод автоматически поймет, что это ручной крафт).

**Пример структуры:**
```text
.minecraft/
 └── ModularContents/
      └── MyAwesomePack/
           ├── pack.json                <- Описание пака (необязательно)
           ├── blocks/                  <- Блоки (.json)
           ├── items/                   <- Предметы (.json)
           ├── weapons/                 <- Оружие ближнего боя (.json)
           ├── tools/                   <- Инструменты (.json)
           ├── armor/                   <- Броня (.json)
           ├── food/                    <- Еда (.json)
           ├── fuels/                   <- Твёрдое топливо (.json)
           ├── recipes/
           │    ├── handcraft/          <- Рецепты для создания прямо в инвентаре (на ходу)
           │    └── my_workbench/       <- Рецепты для вашего кастомного верстака "my_workbench"
           ├── tabs/                    <- Вкладки креатива (.json)
           ├── loot_tables/
           │    ├── airdrops/           <- Таблицы лута для аирдропов (.json)
           │    └── equipment/          <- Пресеты лута для контейнеров (сундуков и т.д.)
           └── assets/                  <- Текстуры и модели (по стандартам ванильных ресурспаков)
```

**`ModularContents/disabled_packs.json`** — список отключённых паков (массив имён папок или архивов).
Переключается чекбоксом `[x]` / `[ ]` слева от имени пака в браузере редактора (F8).
Отключённый пак не загружается ни одним менеджером и не отдаётся клиентам как обязательный.
Рецепты, лут и НПС перезагружаются сразу, блоки и предметы — после перезапуска игры.

```json
["old_pack", "test_pack"]
```

**`ModularContents/theme.json`** — цвета интерфейсов мода (клиентский файл, не часть пака).
Правится на вкладке **Theme** в редакторе (F8) с живым предпросмотром, кнопка **Сохранить** пишет файл.
Значения — `AARRGGBB` или `RRGGBB`; отсутствующие ключи берут значение по умолчанию:

```json
{
  "accent": "FFFFAA00",
  "panel": "FF151515",
  "text": "FFDDDDDD"
}
```

**`pack.json`** — необязательный файл в корне пака. Его содержимое показывается в карточке пака
во внутриигровом редакторе (клавиша F8):

```json
{
  "name": "My Awesome Pack",
  "author": "Ethan",
  "version": "1.0",
  "description": "Zombie apocalypse content"
}
```

## 2. Предметы, Инструменты, Оружие, Броня, Еда

Мод различает несколько типов предметов в зависимости от папки, в которой лежит файл JSON. Во всех предметах можно указывать массив строк `description` для лора предмета.

### 2.1 Обычные предметы (`items/`)
```json
{
  "id": "vip_radio",
  "display_name": "VIP Radio",
  "max_stack_size": 1,
  "creative_tab": "my_tab",
  "max_damage": 5,
  "description": ["Первая строка описания", "Вторая строка"],
  "airdrop_caller": {
    "is_flare": false,
    "delay_min": 100,
    "delay_max": 200,
    "distance_min": 10.0,
    "distance_max": 50.0,
    "loot_table": "military_loot",
    "consume_on_use": true
  }
}
```
* `max_damage`: Прочность предмета. Если `0` — предмет не ломается.
* `airdrop_caller`: Позволяет сделать из предмета рацию или гранату для вызова аирдропа. `is_flare: true` сделает предмет метательным (дымовая граната).

### 2.2 Еда (`food/`)
```json
{
  "id": "canned_beans",
  "display_name": "Банка бобов",
  "heal_amount": 4, 
  "saturation": 0.3,
  "always_edible": false,
  "is_meat": false,
  "potion_effect": "minecraft:regeneration",
  "potion_duration": 100,
  "potion_amplifier": 0,
  "potion_probability": 1.0
}
```
* `heal_amount`: 1 = половинка окорочка, 4 = 2 полных окорочка.
* `saturation`: Насыщение (насколько долго игрок не будет хотеть есть).
* `always_edible`: Можно ли есть, если шкала голода заполнена.
* `potion_effect`: Эффект зелья при съедении, например `minecraft:regeneration`.

### 2.3 Оружие ближнего боя (`weapons/`)
* `attack_damage` (float) — урон оружия в полу-сердцах (добавляется к базовому урону кулака).
* `attack_speed` (float) — скорость атаки (по умолчанию у меча `-2.4`).

### 2.4 Инструменты (`tools/`)
* `tool_type` — тип (`pickaxe`, `axe`, `shovel`, `hoe`).
* `harvest_level` — уровень добычи (0=Дерево, 1=Камень, 2=Железо, 3=Алмаз).
* `efficiency` — скорость копания (2.0=Дерево, 4.0=Камень, 6.0=Железо, 8.0=Алмаз).

### 2.5 Броня (`armor/`)
* `equipment_slot` — `head`, `chest`, `legs`, `feet`.
* `damage_reduction` — единицы защиты (например, Алмазная грудь = 8).
* `toughness` — показатель твердости брони (например, Алмазная = 2.0).
* `armor_texture` — путь к текстуре самой брони на теле игрока.

## 3. Блоки (`blocks/`)

```json
{
  "id": "grass_test",
  "display_name": "Тестовая трава",
  "material": "grass",
  "hardness": 0.6,
  "resistance": 3.0,
  "light_level": 0.0,
  "tool_class": "shovel",
  "harvest_level": 0,
  "block_type": "block",
  "biome_tint": "grass",
  "rotation_type": "none",
  "has_slab": true,
  "has_stairs": true,
  "has_fence": true,
  "has_wall": true,
  "has_door": true,
  "has_trapdoor": true,
  "has_button": true,
  "has_pressure_plate": true
}
```

### Свойства блоков:
* `material` — `rock`, `wood`, `earth`, `iron`, `glass`, `grass`.
* `light_level` — от 0.0 до 1.0 (излучение света).
* `has_slab`, `has_stairs`, `has_fence`, `has_wall`, `has_door`, `has_trapdoor`, `has_button`, `has_pressure_plate` (boolean) — если `true`, мод **автоматически сгенерирует** все полублоки, ступеньки, заборы, стены, двери, люки, кнопки и нажимные плиты для этого блока! Вам не нужно создавать JSON модели для них. Двойные полублоки автоматически объединяются в полноценный блок.
* `rotation_type` — тип вращения при установке:
  * `none` (стандартный)
  * `horizontal` (крутится по 4 сторонам света, как печка)
  * `log` (крутится по 3 осям, как бревно)
  * `prop` (декоративный проп, крутится по 4 сторонам)
* `biome_tint` — `grass`, `foliage`, `water`. Делает блок окрашиваемым в цвет биома (цвет корректно поддерживается и генерируется на блоках, полублоках, ступеньках, заборах и стенах).
* `bounding_boxes` (двойной массив `double[][]`) — позволяет создать кастомные "хитбоксы" (коллизию) для декоративных блоков-пропов. Массив массивов координат `[minX, minY, minZ, maxX, maxY, maxZ]` в пикселях.

## 4. Рецепты и Кастомные Верстаки (`recipes/`)

Мод поддерживает **автоматическое создание новых верстаков**.
Если вы создадите папку `recipes/medic_table/` и положите туда рецепты, мод **автоматически создаст блок верстака** `medic_table`!
Для этого верстака вы сможете использовать свою текстуру и 3D-модель (просто поместив её в `assets/modularcontents/models/block/medic_table.json`).

Папка `recipes/handcraft/` означает рецепты, которые игрок может скрафтить руками. Интерфейс ручного крафта открывается по отдельной кнопке в игре. Если при крафте ваш инвентарь заполнен, крафт будет заблокирован, так как предметы в ручном крафте выдаются прямо в сумку.

**Пример рецепта:**
```json
{
  "id": "make_bandage",
  "category": "medicine",
  "craftingTime": 40,
  "minDrops": 1,
  "movementModifier": 0.5,
  "inputs": [
    {
      "item": "minecraft:wool",
      "count": 2
    },
    {
      "item": "minecraft:shears",
      "count": 1,
      "durability": 5
    },
    {
      "item": "minecraft:water_bucket",
      "count": 1,
      "consume": 0
    }
  ],
  "outputs": [
    {
      "item": "modularcontents:bandage",
      "count": 4,
      "chance": 100.0,
      "nbt": "{CustomNbtTag: 1}"
    },
    {
      "item": "minecraft:string",
      "count": 1,
      "chance": 25.0
    }
  ]
}
```

* `category` — разбивает рецепты по удобным вкладкам слева в интерфейсе. **Внимание:** используйте только латиницу в ID категорий, чтобы не ломался шрифт кнопок!
* `craftingTime` — время крафта в тиках (20 тиков = 1 сек).
* `movementModifier` — замедляет игрока во время крафта (1.0 = нормальная скорость, 0.0 = полная остановка).
* `outputs` — поддерживает несколько выходов:
  * `chance` — шанс получения предмета (например, побочный дроп с вероятностью 25%).
  * `count` — количество получаемых предметов. Интерфейс верстака корректно отобразит цифру количества поверх иконки предмета!
* `minDrops` — минимальное число успешных дропов в случае неудачного срабатывания шансов.
* `inputs` — что тратится на крафт:
  * `count` — сколько предметов должно быть у игрока для крафта.
  * `consume` — сколько из них реально тратится за один крафт (по умолчанию = `count`). Например `count: 4`, `consume: 1` — нужно 4 доски, сгорит только 1, остальные вернутся. `consume: 0` — предмет-катализатор, только требуется, но не тратится.
  * `durability` — сколько прочности снимается с инструмента за один крафт (по умолчанию `1`). Работает только у предметов с прочностью: сам инструмент не тратится, а изнашивается и возвращается игроку; при исчерпании прочности ломается. `durability: 0` — инструмент вообще не изнашивается. Для инструментов `meta` игнорируется, поэтому уже повреждённый инструмент подходит для рецепта.
  * `consume_whole` — `true` означает, что предмет с прочностью не изнашивается, а тратится целиком (исчезает как обычный ресурс). По умолчанию `false` — инструмент изнашивается и ломается только когда кончится прочность. На предметы без прочности не влияет.
  * Инструмент требуется в единственном экземпляре независимо от количества крафтов в очереди, а обычные ресурсы умножаются на количество.
* `nbt` — NBT-тег в формате JSON для кастомных/модифицированных предметов.

Интерфейс верстака сам сгруппирует предметы с одинаковым результатом (но разным NBT/Meta) и позволит циклично их переключать с помощью стрелочек. Группируются только рецепты с **одинаковым набором ингредиентов** — если у рецептов один и тот же результат, но разные ингредиенты (или разные `count`/`consume`/`durability`/`consume_whole`/`nbt` у ингредиентов), они показываются отдельными строками в списке.

## 5. Вкладки Креатива (`tabs/`)

Позволяют группировать ваши предметы из разных паков (и из других модов) в одну вкладку. 

```json
{
  "id": "survival_tab",
  "display_name": "Survival Gear",
  "icon": "minecraft:iron_sword",
  "items": [
    "modularcontents:bandage",
    "minecraft:apple"
  ]
}
```
* `items` список предметов во вкладке. Игровой поиск по этим вкладкам работает корректно благодаря `CreativeTabs.SEARCH`.

## 6. Механика Заполнения Зон (Chest Looting а-ля Тарков)

Мод вводит механику появления лута в контейнерах.
В папке `loot_tables/equipment/` лежат пресеты лута:
```json
{
  "sets": [
    {
      "name": "rare_loot",
      "chance": 10.0,
      "items": [{"item": "minecraft:diamond", "count": 1}]
    }
  ]
}
```
**Как это использовать в игре:**
1. Выдайте себе предмет **Zone Equipment**.
2. В интерфейсе (радаре 256х256) выделите зону с сундуками. Желтые точки — это контейнеры.
3. Выберите пресеты (например, Medical, Ammo) и шансы.
4. Нажмите **Fill**.
5. Все сундуки в этой зоне будут заполнены случайным лутом. Как только сундук будет опустошен игроком, лут начнет медленно раскрываться снова (симуляция постоянного мира).

## 7. Кастомные Модели и Текстуры (Resource Loader)

Внутри вашего контент-пака есть встроенный ресурспак (папка `assets/modularcontents/`).
* Мод **автоматически генерирует базовые JSON-модели в оперативной памяти** для блоков (особенно для ступенек, заборов, стен с поддержкой `biome_tint`). 
* Но если вы хотите дать предмету или верстаку уникальную 3D-модель (например, из Blockbench), просто положите ваш `.json` файл в папку `assets/modularcontents/models/block/` и текстуры в `textures/blocks/`.
* **Правило:** структура `assets` полностью копирует ванильную систему Minecraft ресурспаков.

---

## 8. Полезные Команды и Автоматизация
* `F8` — Открыть интерфейс "Content Creator" для генерации лута, блоков, НПС и рецептов визуально, без написания кода.
* `/mc reload` — Мгновенная перезагрузка (Hot-Reload) всех рецептов, лут-таблиц и характеристик предметов без перезапуска сервера или переоткрытия мира.
* Мод автоматически генерирует `.lang` языковые файлы на основе поля `display_name` у ваших предметов.

## 10. Переплавка (Smelting) и Топливо (Fuel)

Мод поддерживает интеграцию с ванильными печами. Вы можете добавлять новые рецепты переплавки и делать любые свои предметы топливом.

### Топливо (Fuel)
Чтобы любой ваш блок или предмет стал гореть в печке (как уголь или доски), добавьте в его JSON-файл параметр `burn_time`.
* `burn_time: 200` означает, что предмет горит 10 секунд (переплавляет ровно 1 предмет в обычной печке).
* Уголь имеет `burn_time: 1600` (80 секунд, хватает на 8 предметов).
* Ведро лавы: `20000`.

**Пример (В предмет или блок):**
```json
{
  "id": "compressed_coal",
  "display_name": "Сжатый Уголь",
  "max_stack_size": 64,
  "burn_time": 16000
}
```

### Отдельные файлы топлива (`fuels/`)
`burn_time` в JSON предмета работает только для контента самого мода. Чтобы сделать топливом
**любой** предмет — ванильный, из другого мода или свой — положите файл в папку `fuels/`.

**Пример `fuels/example_fuels.json`:**
```json
{
  "id": "example_fuels",
  "item": "minecraft:rotten_flesh",
  "meta": -1,
  "burn_time": 400
}
```
* `item` — полный registry id предмета.
* `meta` — метаданные; `-1` (по умолчанию) означает «любые».
* `burn_time` — время горения в тиках.

Запись из `fuels/` имеет приоритет над `burn_time` внутри JSON предмета, поэтому ей же можно
переопределить время горения уже существующего топлива. Перезагружается по `/mc reload`
и при сохранении из редактора, перезапуск игры не нужен.

### Рецепты переплавки (Smelting)
Рецепты переплавки должны лежать в папке `recipes/smelting/`.
Мод найдет их и добавит во все печи (ванильные и из других модов).

**Пример `recipes/smelting/melt_iron.json`:**
```json
{
  "id": "melt_iron_dust",
  "input": {
    "item": "modularcontents:iron_dust",
    "count": 1
  },
  "output": {
    "item": "minecraft:iron_ingot",
    "count": 1
  },
  "xp": 0.7
}
```
* `xp` — количество опыта, которое игрок получает, забирая предмет из печки. (У железной руды `xp: 0.7`, у алмазов `xp: 1.0`, у булыжника `xp: 0.1`).
